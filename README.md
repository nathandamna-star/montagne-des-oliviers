# Montagne des Oliviers

Application du **Centre Évangélique Montagne des Oliviers** (Tienen) — Centre Évangélique d'Hoegaarden ASBL.
iPhone, Android et site web (espace Responsables), en français et en néerlandais.

Le cahier des charges et les notes techniques sont dans [`CLAUDE.md`](CLAUDE.md).

Commandes utiles :

- `flutter run` : lancer l'app sur un téléphone branché ;
- `flutter run -d chrome` : lancer la version web ;
- `flutter test` : lancer les tests.
